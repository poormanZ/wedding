배경음악 파일을 `bgm.mp3` 이름으로 이 폴더에 넣으세요. config.js의 `bgm` 값과 이름이 같아야 합니다.

- 형식: mp3 (아이폰·안드로이드 모두 재생됨)
- 용량: 3MB 안팎 권장. 길이 2~3분, 128kbps면 충분합니다
- 저작권: 유료 음원을 그대로 올리면 문제가 될 수 있습니다. 저작권 무료(CC0, 로열티 프리) 음원을 쓰세요

모바일 브라우저는 소리 자동재생을 막기 때문에, 화면을 처음 터치할 때 음악이 시작됩니다.
오른쪽 위 ♪ 버튼으로 켜고 끌 수 있습니다.

```sh
# 용량 줄이기 (ffmpeg 필요)
ffmpeg -i 원본.mp3 -b:a 128k -ac 2 bgm.mp3
```
